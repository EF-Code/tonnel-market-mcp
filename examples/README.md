# Examples

The examples use placeholders and local loopback addresses. Replace `<PROJECT_DIR>` with the checkout path and never commit bearer tokens or private absolute paths.

- [config.example.env](config.example.env) — portable environment values.
- [stdio-config.json](stdio-config.json) — generic MCP host configuration.
- [queries.md](queries.md) — evidence-bounded natural-language questions.
- [http-curl.sh](http-curl.sh) — local Streamable HTTP request shape.
