# Security policy

Please do not include secrets, bearer tokens, private database files, or live notification credentials in an issue. For a suspected vulnerability, open a private security report through the repository's configured GitHub security contact when available. If that channel is unavailable, open a minimal public issue containing only a non-sensitive description and request a private contact.

This project is an unofficial read-only marketplace integration. Its HTTP mode is intended for localhost or a controlled network and is not an OAuth authorization server. See [docs/security.md](docs/security.md) for trust boundaries, mitigations, and deployment limits.
